# calendar (RF-04) - área do coordenador

- `WeekAgenda` - visão semanal dos eventos `Visita Individual - [Nome do Candidato]`.
- `PendingVisitsList` - visitas aguardando confirmação com ações Confirmar / Recusar (motivo).
- `AvailabilityEditor` - regras semanais (dia, horário, duração, capacidade) e bloqueios pontuais.
- Exportar `.ics` de um evento para o calendário pessoal.
