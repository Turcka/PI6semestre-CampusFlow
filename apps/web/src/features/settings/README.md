# settings (RNF-04)

- `TenantSettings`: nome, logo, fuso horário, duração padrão da visita, antecedência mínima.
- `CampusesSettings`: campi com endereço e coordenadas centrais (usadas pelo mapa).
- `UsersSettings`: convites, papéis, vínculo coordenador <-> cursos.
- `CoursesSettings`: CRUD de cursos.
- `BillingSettings`: plano, limites, consumo do mês (leads processados, coordenadores ativos, mensagens WhatsApp).
