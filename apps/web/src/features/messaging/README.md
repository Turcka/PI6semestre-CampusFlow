# messaging (RF-05) - Fase 2

- `TemplateEditor`: canal (WhatsApp / e-mail), corpo com variáveis `{{candidato.nome}}` etc., preview renderizado com dados de exemplo; para WhatsApp, vínculo com o nome do template aprovado na Meta.
- `CommunicationRules`: régua por gatilho (confirmação, véspera, 1h antes, pós-visita, cancelamento) -> template e canal.
- `CampaignComposer`: disparo em massa para segmento de leads (marketing/secretaria/financeiro) com anexos e localização.
- `MessageLogs`: histórico com status por mensagem e métricas agregadas.
