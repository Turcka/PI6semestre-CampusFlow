# hooks/

Hooks genéricos (não atrelados a uma feature):

- `useMediaQuery` / `useIsMobile` - alternar sidebar/bottom-nav.
- `useOnlineStatus` - indicador offline no PWA.
- `useGeolocation` - posição atual para rotas no mapa.
- `useDebounce` - buscas em tabelas.
- `useInstallPrompt` - captura `beforeinstallprompt` para o botão "Instalar app".
